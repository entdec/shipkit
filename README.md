# ShipKit

Version bumps apps and gems and generates release notes, by using [AngularJS git commit message standard](https://docs.google.com/document/d/1QrDFcIiPjSLDn3EL15IJygNPiHORgU1_OOAqWjiDU5Y).
Optionally it allows you to specify an LLM it will use to summarise the git commit messages and the whole release.
